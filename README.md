# 🎨 Power BI Themes (Light & Dark)

Repozytorium zawiera zestaw motywów do Power BI oraz instrukcję ich poprawnego użycia.

## 📁 Struktura

- `themes/` – pliki motywów `.json`
- `docs/` – dokumentacja i instrukcje

---

## 🎯 Cel

Zapewnienie spójnego wyglądu raportów Power BI poprzez użycie:
- ☀️ motywu jasnego (light)
- 🌙 motywu ciemnego (dark)

---

## ⚠️ Kluczowa zasada

👉 Motyw należy ustawić **na początku tworzenia raportu**, a nie w trakcie.

Dlaczego?
- motyw działa jako **nakładka (overlay)**
- nie nadpisuje wszystkich wcześniejszych ustawień
- może powodować niespójność wizualną

---
